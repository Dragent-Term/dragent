# Dragent Brand Assets

Master art: `dragent-icon.svg` (1024 grid, Apple squircle). Every asset below
is generated from it — edit the SVG, rerun the export, never hand-edit PNGs.

| File | Use |
|---|---|
| `dragent-icon.svg` | Master. App icon with squircle + transparent corners. |
| `dragent-icon-1024.png` / `-512.png` | App icon exports (transparent corners). Press kits, README badges. |
| `dragent-avatar.svg` | Full-bleed square variant (no rounded corners). |
| `dragent-avatar-1024.png` / `-512.png` | **Socials** — X/GitHub/Discord/LinkedIn avatars. Full-bleed so circular crops never show corners. |

## Store media (`store/`)

One image per LemonSqueezy **product**, not per variant — Pro/Max/Ultra each
carry their monthly and annual variants under a single product, and `credits`
holds all the one-time packs, so four images cover the whole store.

Regenerate with `python3 brand/gen-store-media.py`. Two constraints are baked
into the script and are easy to break by eye:

- **4:3 at 1652×1240** is what LemonSqueezy asks for, but it derives its own
  **square** thumbnails, which crop the *sides*. Everything legible therefore
  lives inside the centre 1240px; the outer band is atmosphere only.
- **qlmanage cannot rasterise a 4:3 SVG directly** — it always emits a square,
  scaling to fit the height and cropping the width *from the left*, which
  silently deletes the right quarter of the art. The script authors on a
  1652×1652 canvas and crops the 4:3 band back out with `sips`.
