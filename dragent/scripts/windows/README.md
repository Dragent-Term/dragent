# Windows installer (Inno Setup)

`windows-installer.iss` builds Dragent's Windows setup `.exe` with [Inno Setup 6](https://jrsoftware.org/isdl.php). It gives the standard wizard flow — **Welcome → Destination → Select Additional Tasks (Create a desktop shortcut) → Ready to Install → Installing → Finish (Launch Dragent)** — with the app banner/logo on the wizard pages.

## Prerequisites
- Windows with **Inno Setup 6** installed (`ISCC.exe`, usually at `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`).
- Attach the app icon + manifest to the exe with a `build.rs` using the [`winres`](https://crates.io/crates/winres) crate — the installer's shortcuts reuse the exe's embedded icon, so no separate `.ico` is needed for them.

## Build it (one command)
`scripts\package-windows.ps1` builds the app, stages the runtime layout, zips it, **and** compiles this installer:
```powershell
.\scripts\package-windows.ps1 -Build
```
Outputs into `dist\`:
- `Dragent-<version>-windows-x86_64.zip` (portable), and
- `Dragent-<version>-windows-x64-setup.exe` (installer).

If Inno Setup isn't installed the script still produces the zip and prints a hint (or pass `-NoInstaller` to skip the installer step).

## Build the installer only (manual)
The script hands the `.iss` its paths via `/D` overrides; to run `ISCC` yourself, point it at the staged folder (`dist\windows-dragent`, created by the packaging script) or your own folder containing `dragent.exe`:
```
ISCC.exe /DAppVersion=0.1.0 /DReleaseDir=<abs path to staged files> /DOutDir=<abs dist> scripts\windows\windows-installer.iss
```
With no `/D` flags it uses the defaults baked into the script (`ReleaseDir = ..\..\dist\windows-dragent`, `OutDir = ..\..\dist`).

## Keep the AppId stable
`#define AppId` in the `.iss` is the app's Windows identity. **Never change it between releases** — Windows uses it to recognise upgrades. Generate your own GUID once (Inno Setup IDE → *Tools ▸ Generate GUID*) and paste it in.

## Branding images (`installer-images/`)
| File | Used for | Size |
|------|----------|------|
| `dragent-banner.bmp` | `WizardImageFile` — large side image (Welcome / Ready-to-Install) | 164 × 314 |
| `dragent-logo.bmp` | `WizardSmallImageFile` — header logo on later pages | 55 × 58 |
| `dragent.ico` | `SetupIconFile` — the installer .exe's own icon | multi-res |

The two BMPs checked in here are **24-bit** (Inno-friendly on all versions) and are generated by **`gen-installer-art.py`** from `app/assets/dragent/icons/dragent-icon.png`. It paints a diagonal gradient + subtle dot texture + a soft glow behind the icon, with the wordmark on the banner, in the brand accent (`BRAND_ACCENT` pinned in the script; set it to `None` to auto-derive a colour from the icon instead). To regenerate (e.g. after a new icon):
```sh
# needs Pillow; use a venv if your Python is externally managed (PEP 668)
python3 -m venv .venv && .venv/bin/pip install pillow
.venv/bin/python scripts/windows/gen-installer-art.py
```
Tweak colours/pattern/text inside that script. Swap in fully custom designer art any time — just keep the sizes (164×314, 55×58) and 24-bit BMP format.

`dragent.ico` is a copy of `app/assets/resources/windows/dragent.ico` (wired via `SetupIconFile`) — refresh it from there whenever the app icon changes.

## Code signing
For a real release, sign both the app exe and the finished installer with `signtool.exe` (EV certificate) to avoid SmartScreen warnings — see `bundling_and_deployment.md`.

## Notes
- Installs **per-user** by default (no admin prompt); the user can elevate to all-users on the privileges page.
- The desktop shortcut is opt-in via the **Select Additional Tasks** page. The shortcut sets `AppUserModelID` (`dev.dragent.app`) so all Dragent windows group under one taskbar button — this is also the anchor for a future Windows **taskbar jump list** ("New Window" task), the Windows analogue of the macOS dock menu.
